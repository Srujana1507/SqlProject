DUAL

In Oracle, DUAL is a system-defined special purpose table, with exactly a single row and a single column named DUMMY, which contains the value 'X'.


Why DUAL Table

  • Perform arithmetic operations or expressions without referencing actual tables.
  • Retrieve system variables or functions results.
  • Test queries or expressions.
  • Create dummy data for testing purposes.

Basic Syntax

SELECT expression FROM DUAL ;

In Other Databases like MySQL or SQL Server, etc..

They do not have a dedicated DUAL table. However, they allow queries without FROM clauses for similar purposes.

SELECT expression ;

Key Points to Remember

  • DUAL is a special-purpose table; it does not hold real data.
  • It is specific to Oracle but conceptually available across RDBMS systems in different forms.
  • Alternatives exist in other systems like MySQL (SELECT without FROM) or PostgreSQL (use of VALUES).

Structure of DUAL Table

SELECT * FROM DUAL ;

Output:

DUMMY
---------
X

Examples

Scenario 1:- Perform addition using the DUAL table

SELECT 10 + 20 AS total FROM DUAL ;

SQL Server & MySQL

SELECT 10 + 20 ;

Scenario 2:- Returning a Constant string, e.g. display Hello SQL

SELECT 'Hello, SQL!' AS Greeting FROM DUAL ;

Scenario 3:- Using Date Functions

SELECT SYSDATE AS Current_date FROM DUAL ;

In SQL Server

SELECT GETDATE() ;

Scenario 4:- Concatenating Strings

SELECT 'Hello, ' || 'World!' AS Message FROM DUAL ;

Scenario 5:- Generating Sequences numbers from 1 to 5.

SELECT ROWNUM AS Seq_no FROM DUAL CONNECT BY LEVEL <= 5 ;

Scenario 6:- Evaluating Complex Expressions

SELECT POWER( 2, 3 ) AS Exponent_Result FROM DUAL ;

Scenario 7:- Evaluate a conditional expression using CASE

SELECT CASE WHEN 5 > 3 THEN ' True ' ELSE ' False ' END AS result FROM DUAL ;

Scenario 8:- Retrieve current user using Metadata functions.

SELECT USER AS Current_user FROM DUAL ;

Scenario 9:- Use Mathematical Functions. e.g Find the square root of a number.

SELECT SQRT(16) AS square_root FROM DUAL ;

Scenario 10:- Test String Functions. e.g Convert a string to uppercase.

SELECT UPPER ( 'hello') AS uppercase_string FROM DUAL ;

Scenario 11:- Create dummy rows for testing.

SELECT 'Test Data' AS dummy_column FROM DUAL ;

Do’s and Don’ts with DUAL

Do's :-

  • Use DUAL for computations and function evaluations in Oracle.
  • Utilize it for generating rows in recursive queries (Oracle-specific).
  • Use DUAL when a table is not required but a syntactically valid SQL statement is needed.

Don'ts :-

  • Avoid overusing DUAL in complex queries where actual data is involved.
  • Do not assume DUAL is available in all databases; some systems like MySQL allow operations without a table reference.
