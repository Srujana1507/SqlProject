GROUP BY


  • GROUP BY clause is used to group rows with the same values in specified columns into summary rows.
  • It is often used with aggregate functions like COUNT(), SUM(), AVG(), MAX(), and MIN() to perform operations on each group.

Syntax :-


SELECT column1 ,aggregate_function(column2), column3
FROM table_name
WHERE column1 ,column3 ;

behavior :-

  • Columns specified in the SELECT clause must either appear in the GROUP BY clause or be used in aggregate functions.
  • Rows with NULL values in the grouping column are treated as a separate group.

Key Concepts :-

  • Grouping Data :-Rows with the same values in the specified columns are grouped together.
  • Used with Aggregate Functions :-Functions like SUM, COUNT, AVG, MIN, MAX operate on each group.
  • Order of Execution :- GROUP BY is applied after the WHERE clause but before the HAVING and ORDER BY clauses.
  • Columns in SELECT :- Columns listed in the SELECT statement must either appear in the GROUP BY clause or be used in an aggregate function.

Examples of GROUP BY

1. Basic Grouping

Scenario 1: Retrieve the total sales for each department.


SELECT Department ,SUM(Sales) AS TotalSales
FROM Employees
GROUP BY Department ;

Scenario 2: Count the number of employees in each department.


SELECT Department ,COUNT(*) AS EmployeeCount
FROM Employees
GROUP BY Department ;

2. Using GROUP BY Without Aggregate Functions


Scenario 1: List unique department IDs in the employees table.


SELECT department_id
FROM Employees
GROUP BY department_id ;
- - Returns one row for each unique department_id

3. Grouping with NULL Values

Scenario : When a column has NULL values, they form their own group


Example Data:

EmployeeID department_name
1 HR
2 Sales
3 NULL
4 HR
SELECT department_name ,COUNT(*) AS EmployeeCount
FROM Employees
GROUP BY department_name ;
- - NULL values are treated as a separate group.

Output Data:

department_name EmployeeCount
HR 2
Sales 1
Null 1

4. Using Aggregate Functions with multiple columns

Scenario : Count the number of employees in each department


SELECT department_name ,JobTitle,SUM(Sales) AS TotalSales
FROM Employees
GROUP BY department_name, JobTitle ;
- - Groups employees by department_id and job_title.
- - Calculates the sum of salaries for each combination of department and job role.

Advanced Examples


1. GROUP BY with HAVING Clause

Scenario : Find departments where the total salary exceeds 200,000.


SELECT department_id ,SUM(salary) AS total_salary
FROM employees
GROUP BY department_id
HAVING SUM(salary) > 200000 ;
- - Groups employees by department_id.
- - Filters groups based on the SUM(salary) using the HAVING clause.

3. GROUP BY with Window Functions

Scenario : Retrieve each department's total sales alongside each employee's contribution percentage.


SELECT Department ,EmployeeID , Sales,
(Sales * 1.0 / SUM(Sales) OVER (PARTITION BY Department ) ) * 100 AS ContributionPercentage
FROM Employees ;
- - The SUM() window function calculates the total sales for each department without collapsing rows.

4. GROUP BY with ORDER BY

Scenario : Retrieve Groups employees by department_id and display by total_salary in descending order.


SELECT department_id , SUM(salary) AS total_salary
FROM employees
GROUP BY department_id
ORDER BY total_salary ;
- - The SUM() window function calculates the total sales for each department without collapsing rows.

5. Nested Grouping

Scenario : Find the maximum sales within each department, and then filter for departments where the maximum exceeds $5,000.


WITH MaxSalesPerDept AS (
    SELECT department_id , MAX(Sales) AS MaxSales
    FROM employees
    GROUP BY department_id
    )
SELECT *
FROM MaxSalesPerDept
WHERE MaxSales > 5000 ;
- - The SUM() window function calculates the total sales for each department without collapsing rows.

6. Handling Complex Expressions in Grouping

Scenario : Group by a calculated field (e.g., age group).


SELECT
    CASE
      WHEN Age < 30 THEN 'Under 30'
      WHEN Age BETWEEN 30 AND 50 THEN '30-50'
      ELSE 'Over 50'
    END AS AgeGroup
    COUNT( *) AS Count
FROM employees
GROUP BY
    CASE
      WHEN Age < 30 THEN 'Under 30'
      WHEN Age BETWEEN 30 AND 50 THEN '30-50'
      ELSE 'Over 50'
    END ;

Database-Specific Notes


1. Oracle


Oracle allows grouping by functions or expressions.


SELECT TRUNC(hire_date, 'YYYY') AS Year, COUNT( * ) AS employee_count
FROM Employees
GROUP BY TRUNC(hire_date, 'YYYY') ;

2. SQL Server


SQL Server supports grouping by computed columns or expressions.


SELECT YEAR (order_date) AS order_year, COUNT( * ) AS order_count
FROM orders
GROUP BY YEAR (order_date) ;

3. MySQL


MySQL allows aliases in the GROUP BY clause starting from version 8.0.


SELECT customer_id , COUNT(order_id) AS order_count
FROM orders
GROUP BY customer_id ;

Best Practices for GROUP BY

  • Avoid GROUP BY on Columns with High Cardinality :- Grouping on unique columns (like primary keys) may result in no effective grouping.
  • Use HAVING for Aggregate Filters :-Apply aggregate filters with HAVING, not WHERE.
  • Optimize with Indexes :- Ensure that the columns in the GROUP BY clause are indexed for better performance.
  • Be Mindful of NULLs :- Null values are treated as a distinct group.
  • Combine GROUP BY with ORDER BY :- Use ORDER BY to sort grouped data for better readability.
  • Minimize Columns in GROUP BY :- Include only necessary columns to avoid generating overly granular groups.
  • Combine with WHERE :-Use WHERE to filter rows before grouping to improve query performance.
  • Use Meaningful Aliases :-Use descriptive aliases for calculated fields in the SELECT clause.

Do's and Don'ts

Do's :-

1. Always Include Non-Aggregated Columns in GROUP BY

  • Ensure all non-aggregated columns in the SELECT clause appear in the GROUP BY clause.
  • Example

    • SELECT department_name ,SUM(Sales) FROM Employees GROUP BY department_name ;

2. Use HAVING for Filtering Groups

  • Use HAVING to filter aggregated results.
  • Example

    • SELECT department_name ,SUM(Sales) FROM Employees
    GROUP BY department_name
    HAVING SUM(Sales) > 10000 ;

Don'ts :-


Avoid Mixing Aggregated and Non-Aggregated Columns Without Grouping:

    SELECT department_name ,Sales FROM Employees
    GROUP BY department_name

    - - Incorect

Don’t Overuse GROUP BY :-

  • Avoid unnecessary grouping when a simple query suffices.
