Python Beginner


1. What is Python?


Python is a high-level, interpreted programming language created by Guido van Rossum in 1991. It is known for its simple syntax and readability, which makes it easy to learn and use. Python is cross-platform (works on Windows, Linux, and macOS) and is widely used for:


  • Web Development
  • Software Development
  • Data Analysis
  • Machine Learning
  • Automation


2. What is namespace in python


A namespace in Python is a container that holds names (variables, functions, objects) and maps them to their corresponding values to avoid naming conflicts.


Types of Namespaces:


  • Local:Names defined inside a function (temporary).

  • Global:Names defined at the top level of a script or module.

  • Built-in:Predefined names like print() and len().

    • Example:

    x = "global" # Global namespace
    def my_function():
      x = "local" # Local namespace
      print(x)
    my_function()
    print(x)

    Output:

    local
    global


    3. What is a Python dictionary? Give an example.


    A dictionary is a collection of key-value pairs. Keys must be unique.


    Example:

    my_dict = {'name': 'Alice', 'age': 25}
    print (my_dict['name'])

    Output:

    Alice

    4. What is a Python list? Provide an example.


    A list is an ordered, mutable collection used to store multiple items. It is defined using square brackets [].


    Example:

    my_list = [1, 2, 3, "hello"]
    print(my_list[2])

    Output:

    3


    5. What is a tuple in Python? Provide an example.


    A tuple is an ordered, immutable collection. It is defined using parentheses ().


    Example:

    my_tuple = (1, 2, 3, "hello")
    print(my_tuple[3])

    Output:

    hello

    6.What are Python data types?


  • Text Type: str

  • Numeric Types: int, float, complex

  • Sequence Types: list, tuple, range

  • Mapping Type: dict

  • Set Types: set, frozenset

  • Boolean Type: bool

  • Binary Types: bytes, bytearray, memoryview


    • 7. What is indentation in Python? Provide an example.


    In Python, indentation refers to the spaces or tabs used at the beginning of a line to define the structure and blocks of code. Unlike many other programming languages that use curly braces {} or keywords to define blocks, Python uses indentation to group statements.


    Proper indentation is mandatory in Python. Improper or inconsistent indentation will result in a IndentationError.


    Example 1: Correct Indentation

    if True:
        print("Indented correctly") # Indented block

    Output:

    Indented correctly

    Example 2: Incorrect Indentation

    if True:
    print("This is not indented correctly.") # No indentation for block

    Output:

    IndentationError: expected an indented block


    8. How do you write a comment in Python? Provide an example.


    In Python, you can write comments in two ways:


  • Single-line comment: Use # before the comment.

  • Multi-line comment: Use triple quotes """ or '''.

    • Example:

    # This is a single-line comment

    """
    This is a multi-line comment.
    """


    9. What are Python control statements?


    Control statements manage the flow of execution in a program. They include:


  • if, elif, else: Conditional statements to perform actions based on conditions.

  • for, while: Looping statements to repeat actions.

  • break, continue, pass: Loop control statements to modify the flow inside loops.


    • Example:

    x = 5
    if x > 0:
        print("Positive number")
    elif x < 0:
        print("Negative number")
    else:
        print("Zero")

    Output:

    Positive number


    10. What is the difference between is and ==?


  • is: Checks if two objects refer to the same memory location.


  • ==: Checks if the values of two objects are equal.


    • Example:

    a = [1, 2, 3]
    b = [1, 2, 3]
    c = a

    print(a == b) # True, values are equal
    print(a is b) # False, different memory locations
    print(a is c) # True, same memory location

    Output:

    True
    False
    True
