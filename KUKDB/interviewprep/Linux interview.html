Linux Beginner


1. What is Linux?


Linux is an open-source operating system based on Unix. It is widely used for servers, desktops, and embedded systems. It provides a robust, secure, and stable environment, and comes in many distributions like Ubuntu, CentOS, Debian, and Fedora.



2. What is the Linux kernel?


The Linux kernel is the core of the Linux operating system. It manages system resources, hardware communication, and basic system operations like memory and process management.



3. What are some common Linux distributions?


  • Ubuntu

  • Debian

  • Fedora

  • CentOS

  • Red Hat Enterprise Linux (RHEL)



4. What is a shell in Linux?


A shell is a command-line interface that allows users to communicate with the Linux operating system. It interprets user commands and executes them. Popular shells include Bash, Zsh, and Fish.



5. What is the difference between a command and a program in Linux?


A command is an instruction entered into the shell, while a program is a compiled or interpreted set of instructions stored on disk. Commands can be built into the shell or refer to external programs.



6. What are hidden files in Linux?


Hidden files in Linux are files or directories that begin with a dot (.) in their name. They are not shown in normal directory listings unless you use ls -a. These files typically store configuration settings.



7. Why are permissions important in Linux?


Permissions define which users can read, write, or execute a file or directory. This protects sensitive data and prevents unauthorized or accidental changes to system files.



8. What is the root user in Linux?


The root user is the administrative superuser account in Linux. It has full control over the system, allowing unrestricted access to all files and commands. It is typically used for maintenance or configuration tasks.



Linux commands


📁 File and Directory Management


pwd # Show current working directory

ls # List files and directories

ls -l # List with detailed file information

ls -a # Include hidden files in list

cd /path/to/dir # Change to specific directory

cd .. # Go up one directory level

mkdir new_folder # Create a new directory

touch newfile.txt # Create an empty file

mv oldname.txt newname.txt # Rename a file

mv file.txt /path/to/location/ # Move file to another location

cp file1.txt file2.txt # Copy a file

cp -r dir1/ dir2/ # Copy a directory and its contents

rm file.txt # Delete a file

rmdir empty_folder # Remove an empty directory

ln -s /path/to/original symlink_name # Create a symbolic link


📝 File Viewing and Editing


cat file.txt # Display contents of a file

less file.txt # View file one page at a time

head -n 10 file.txt # Show first 10 lines of a file

tail -n 10 file.txt # Show last 10 lines of a file

nano file.txt # Edit a file in Nano editor

vi file.txt # Open file in Vi editor


⚙️ Process Management


ps aux # Show all running processes

top # Live view of CPU/memory usage

htop # Enhanced version of 'top' (if installed)

kill PID # Terminate a process by PID

kill -9 PID # Force kill a process

nice -n 10 command # Run command with altered priority


💻 System Information


uname -a # Show system and kernel info

df -h # Show disk usage in human-readable format

du -sh /path # Show size of specific directory

free -m # Show memory usage in MB

uptime # Show how long the system has been running

hostname # Show or set system hostname

date # Show current system date and time


👤 User and Group Management


whoami # Show current logged-in user

id # Show user ID and group ID

adduser newuser # Add a new user

passwd newuser # Set or change password for a user

su username # Switch to another user

sudo command # Run a command with superuser privileges

groups # Show groups current user belongs to


🌐 Network Configuration and Monitoring


ifconfig # Show IP and network interfaces (deprecated)

ip a # Display IP addresses (modern replacement)

ping google.com # Check network connectivity

netstat -tuln # Show open ports and services

ss -tuln # Modern alternative to netstat

hostname -I # Show local IP address

curl http://example.com # Fetch content from a URL


📦 Package Management (Debian/Ubuntu)


sudo apt update # Update package lists

sudo apt upgrade # Upgrade all installed packages

sudo apt install packagename # Install a new package

sudo apt remove packagename # Remove a package

dpkg -l # List all installed packages

apt-cache search keyword # Search for a package


📦 Package Management (RHEL/CentOS)


sudo yum update # Update all packages

sudo yum install packagename # Install a package

sudo yum remove packagename # Remove a package

rpm -qa # List all installed RPM packages

yum search keyword # Search for a package

Linux Advanced


1. Explain the difference between hard link and soft link.


A hard link points directly to the inode of a file, meaning both original and link share the same data blocks. A soft link (symbolic link) is a pointer to the file name, not the data. If the original file is deleted, the soft link becomes broken.



2. How do you change the ownership of a file?


Use the command: chown user:group filename



3. How do you schedule a task using cron?


Use crontab -e to edit the crontab and schedule tasks. Syntax: * * * * * command (minute, hour, day, month, weekday).



4. How can you find the top 10 memory-consuming processes?


Use: ps aux --sort=-%mem | head -n 10



5. How do you find a specific string in a file?


Use the command: grep "string" filename



6. How do you check which ports are open?


Use: netstat -tuln or ss -tuln



7. How can you archive and compress files in Linux?


Use: tar -czvf archive.tar.gz file_or_directory



8. What is the purpose of the umask?


umask sets default file permissions for newly created files and directories. For example, a umask of 022 results in files being created with permission 755.



9. How do you count the number of lines, words, and characters in a file?


Use: wc filename or wc -l for lines, -w for words, and -c for characters.



10. How do you view and kill a running process?


Use ps aux or top to view processes. Kill using: kill PID or kill -9 PID to force kill.



11. How do you check memory usage by each process?


You can use the top or htop commands to view memory usage. For a sorted view by memory, use ps aux --sort=-%mem.



12. What is SELinux?


SELinux (Security-Enhanced Linux) is a Linux kernel security module that enforces access control policies. It adds another layer of security by defining which users and processes can access which files and resources.



13. How do you secure SSH access on a Linux server?


Use strong passwords or SSH keys, disable root login by editing /etc/ssh/sshd_config, change the default port, enable firewall rules, and use fail2ban to block brute-force attacks.



14. What is the use of the /proc directory?


The /proc directory is a virtual filesystem providing system and process information. It contains runtime system data, including CPU, memory, and kernel parameters.



15. How can you find which files were recently modified?


Use the find /path -type f -mtime -n command, where n is the number of days.



16. What is the difference between TCP and UDP?


TCP is connection-oriented and reliable, ensuring packet delivery and order. UDP is connectionless and faster, but does not guarantee delivery or order.



17. How do you view logs in Linux?


Most logs are stored in /var/log. You can use cat, less, or tail -f /var/log/syslog (or /var/log/messages) to view logs.



18. How do you add a user to a group in Linux?


Use the command: usermod -aG groupname username



19. What is inode in Linux?


An inode is a data structure that stores metadata about files, including ownership, permissions, size, and disk location, but not the filename.



20. How do you display disk partition information?


Use commands like lsblk, fdisk -l, or parted -l to view partition details.



21. How do you check open files by a process?


Use: lsof -p PID, replacing PID with the process ID.



22. What are sticky bits in Linux?


A sticky bit, when set on a directory (e.g., chmod +t /tmp), allows only the file’s owner or root to delete or rename files inside it, even in shared directories.



23. How do you check system boot time?


Use uptime or who -b to see when the system last booted.



24. How do you find large files in Linux?


Use: find / -type f -size +100M to list files larger than 100MB.



25. What is the difference between fork() and exec()?


fork() creates a new process, duplicating the parent, while exec() replaces the current process memory with a new program.



26. How do you limit memory or CPU usage of a process?


You can use ulimit for session-based limits or cgroups for managing resource usage on a system-wide level.



27. How do you mount a filesystem manually?


Use: mount /dev/sdX /mnt, where /dev/sdX is your device name and /mnt is the mount point.



28. What is the purpose of systemctl?


systemctl is a command to manage services in systems using systemd. For example, systemctl restart apache2 restarts the Apache web server.



29. How do you list all users in Linux?


Use cat /etc/passwd. Each line represents a system user and includes information like username, UID, home directory, and default shell.



30. How do you check whether a service is running?


Use systemctl status service_name or ps aux | grep service_name to confirm if a service is active.

Linux Expert

1. How does SELinux enhance Linux security?


SELinux (Security-Enhanced Linux) provides a mechanism for supporting access control security policies through mandatory access controls (MAC). It confines user programs and system servers to the minimum amount of privilege they require to do their jobs. This minimizes damage from misconfigurations or vulnerabilities.



2. What is the difference between cgroups and namespaces in Linux?


Namespaces provide isolation of system resources (like PID, mount, network) between processes, while cgroups limit, account for, and isolate the resource usage (CPU, memory, disk I/O) of process groups. They are both key components of Linux containers and used by tools like Docker and Kubernetes.



3. How do you debug performance issues using perf?


perf is a powerful performance analyzing tool. To record and analyze CPU cycles, use:
perf record -g ./my_app
Then view with:
perf report
This helps identify bottlenecks, hot paths, and CPU usage per function.



4. Explain how to tune kernel parameters at runtime.


You can use sysctl to modify kernel parameters:
sysctl -w net.ipv4.ip_forward=1
Permanent changes can be made in /etc/sysctl.conf or /etc/sysctl.d/*.conf.



5. What are the main differences between ext4, XFS, and Btrfs?


- ext4: Stable and widely used, good general-purpose performance. - XFS: High-performance journaling file system, optimized for large files and parallel I/O. - Btrfs: Modern FS with features like snapshots, compression, and built-in RAID, still under active development.



6. How do you trace system calls of a process?


Use strace to monitor system calls:
strace -p <PID>
This is useful for debugging issues related to file access, networking, and permissions.



7. How does auditd work in Linux security?


auditd is the userspace component to the Linux Auditing System. It collects information on system calls, file accesses, or command executions as per rules defined with auditctl, aiding in security compliance and forensic analysis.



8. What are hugepages in Linux and why are they used?


Hugepages are memory pages significantly larger than the default size (e.g., 2MB instead of 4KB). They reduce TLB (Translation Lookaside Buffer) misses and improve performance in memory-intensive applications like databases.



9. How do you isolate CPU cores for real-time applications?


Use isolcpus kernel boot parameter to isolate specific cores, and bind processes to them using:
taskset -c <core> <command>



10. What is eBPF and how is it used in Linux?


eBPF (extended Berkeley Packet Filter) allows sandboxed programs to run in the kernel space safely. It’s used for tracing, monitoring, security enforcement (like XDP), and system observability without changing kernel source.



11. How can you find memory leaks in Linux processes?


You can use valgrind to detect memory leaks in applications:
valgrind --leak-check=full ./app
It provides detailed information about memory usage, leaks, and unfreed memory.



12. What is NUMA and how is it managed in Linux?


NUMA (Non-Uniform Memory Access) is a memory design where memory access time depends on the memory location relative to the processor. Linux supports NUMA balancing and tools like numactl to control CPU/memory bindings for performance tuning.



13. How do you troubleshoot high I/O wait in Linux?


Use tools like iostat, iotop, or dstat to identify I/O bottlenecks. High I/O wait means the CPU is waiting for disk operations to complete, often indicating disk performance issues.



14. How do Linux containers work under the hood?


Containers use Linux features like namespaces for isolation (PID, net, mount) and cgroups for resource limitation. Tools like Docker and Podman abstract these kernel features to provide lightweight virtualization.



15. How can you secure SSH access on a Linux server?


- Disable root login by setting PermitRootLogin no in /etc/ssh/sshd_config - Use key-based authentication - Change default port from 22 - Use firewall and fail2ban to prevent brute-force attacks



16. What is the difference between hard links and soft links?


- Hard link is a mirror copy of a file that shares the same inode. Deleting the original doesn't affect the link. - Soft link (symbolic) points to the filename and will break if the original file is deleted.



17. How can you detect kernel panics or crashes in Linux?


Check logs via dmesg, /var/log/messages, or configure kdump to capture crash dumps for post-mortem analysis.



18. How does Linux handle deadlocks?


Linux doesn’t automatically prevent or resolve deadlocks. Developers need to implement logic to prevent them through proper locking mechanisms. Tools like lsof and ps help identify blocked resources.



19. What is systemd and how is it different from SysVinit?


systemd is a modern init system used in most Linux distros. It offers parallel startup, service dependency management, and centralized logging. Unlike SysVinit, it uses unit files instead of shell scripts.



20. How do you analyze boot performance in Linux?


Use systemd-analyze to get total boot time and systemd-analyze blame to list services by time taken. This helps identify delays in the boot process.



21. How can you debug system performance using perf?


perf is a powerful tool for performance analysis. It can trace CPU cycles, cache misses, and kernel functions. Example:
perf top – shows real-time CPU usage by functions.



22. How do you manage swap space in Linux?


Use the following to create and activate swap:
fallocate -l 1G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile



23. What is SELinux and how does it enhance system security?


SELinux (Security-Enhanced Linux) enforces mandatory access control (MAC). It restricts processes based on policies even if a user is root, adding an extra layer of security.



24. How do you trace a process system call in real time?


Use strace to trace system calls made by a process:
strace -p <PID>



25. What is the difference between cron and systemd timers?


cron is the traditional scheduler using crontabs. systemd timers are newer and support dependency management, logging, and more flexible event handling.



26. How can you recover a deleted file in Linux?


If the file was on an ext3/ext4 system, you might use tools like extundelete. Recovery depends on disk usage since deletion.



27. How do control groups (cgroups) help in resource management?


cgroups limit CPU, memory, and I/O for a group of processes. They’re useful in containers or when isolating resource-heavy processes. Example: Docker uses cgroups under the hood.



28. What is the purpose of auditd in Linux?


auditd is the userspace component of the Linux Auditing System. It logs security-relevant events (file access, permission changes, etc.) to help track suspicious activity.



29. How do you analyze and control network bandwidth per process?


Use tools like iftop or nethogs for real-time monitoring, or tc (traffic control) for limiting bandwidth per interface/process.



30. How do namespaces isolate containers in Linux?


Namespaces provide isolation of PID, network, filesystem, and more. Each container runs with its own namespace, ensuring separation from the host and other containers. Example: unshare --net --pid --mount
