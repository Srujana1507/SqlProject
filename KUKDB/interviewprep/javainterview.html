1. What are the features of Java?


  • Platform Independent

  • Object-Oriented

  • Robust and Secure

  • Multi-threaded

  • High Performance

  • Dynamic and Extensible

  • Distributed

2. Explain the concept of OOPs in Java.


  • OOPs (Object-Oriented Programming) is a programming paradigm based on objects and classes.

  • Key concepts include :

    • Inheritance : Acquiring properties of a parent class.

    • Polymorphism : Performing tasks in multiple ways (method overloading/overriding).

    • Encapsulation : Wrapping data and code into a single unit (class).

    • Abstraction : Hiding implementation details and showing only functionality.

3. What is the difference between JDK, JRE, and JVM?


  • JDK (Java Development Kit) : Includes tools for developing and debugging Java applications.

  • JRE (Java Runtime Environment) : Provides libraries and JVM required to run Java applications.

  • JVM (Java Virtual Machine) : Executes Java bytecode and provides runtime environment.

4. What are access modifiers in Java?


  • Access modifiers define the scope of access :

  • Public : Accessible everywhere.

  • Private : Accessible within the same class only.

  • Protected : Accessible within the same package and subclasses.

  • Default (no modifier) : Accessible within the same package.

5. What is the difference between == and equals() in Java?


  • == : Compares reference (memory location) of objects.

  • equals() : Compares content or value of objects (default implementation in Object class can be overridden).

6. What is a constructor in Java?


  • A constructor is a special method used to initialize objects.

  • Characteristics:

  • Same name as the class.

  • No return type.

  • Called automatically when an object is created.

  • Can be overloaded.

7. What is the difference between method overloading and overriding?


  • Overloading : Same method name but different parameters (compile-time polymorphism).

  • Overriding : Subclass redefines a method of the parent class (runtime polymorphism).

8. What is the difference between ArrayList and LinkedList?


  • ArrayList :

    • Uses a dynamic array.

    • Faster for retrieval.

    • Slower for insertion/deletion in the middle.

  • LinkedList :

    • Uses a doubly linked list.

    • Slower for retrieval.

    • Faster for insertion/deletion.

9. What are exceptions in Java? How are they handled?


  • Exceptions are unwanted events that disrupt normal flow.

  • Handled using :

    • try-catch block

    • finally block (optional, for cleanup)

    • throw and throws keywords

10. What is the difference between abstract class and interface?


  • Abstract Class:

    • Can have abstract and non-abstract methods.

    • Supports constructors.

    • Allows single inheritance.

  • Interface :

    • All methods are abstract by default (from Java 8, can have default/static methods).

    • No constructors.

    • Supports multiple inheritance.

11. What is the final keyword in Java?


  • Final Variable : Cannot be changed once assigned.

  • Final Method : Cannot be overridden.

  • Final Class : Cannot be subclassed.

12. Explain the concept of static keyword in Java.


  • Static Variable : Shared among all instances of the class.

  • Static Method : Can be called without creating an object.

  • Static Block : Used for static initialization.

13. What is the difference between String, StringBuilder, and StringBuffer?


  • String : Immutable, thread-safe.

  • StringBuilder : Mutable, not thread-safe, faster.

  • StringBuffer : Mutable, thread-safe, slower than StringBuilder.

14. Write a program to check if a number is prime.


    public class PrimeCheck {
      public static void main(String[] args) {
        int num = 29; // Example number
        boolean isPrime = true;
        if (num <= 1) {
          isPrime = false;
        } else {
          for (int i = 2; i <= Math.sqrt(num); i++) {
            if (num % i == 0) {
              isPrime = false;
              break;
            }
          }
        }
        System.out.println(num + " is " + (isPrime ? "a prime number" : "not a prime number"));
      }
    }

16. What is the difference between an interface and a class?


  • Class : Can have fields, methods, constructors, and blocks of code. It can implement multiple interfaces.

  • Interface : Defines a contract that implementing classes must follow. All methods are abstract (before Java 8). Cannot have constructors.

17. What is the difference between this and super in Java?


  • this : Refers to the current object. Used to access the current class members.

  • super : Refers to the immediate parent class object. Used to access the parent class methods and constructors.

18. Explain the concept of garbage collection in Java.


  • Garbage collection is the process of automatically reclaiming memory occupied by unused objects to avoid memory leaks.

    • System.gc() can be used to request garbage collection, but it is not guaranteed.

19. What is the difference between throw and throws?


  • throw : Used to explicitly throw an exception from a method or block.

  • throws : Declares the exceptions that a method might throw to the caller.

20. What are Wrapper Classes in Java?


  • Wrapper classes convert primitive data types into objects.

  • Example :

    int → Integer,
    double → Double.

    They are used in collections (which work with objects, not primitives).

21. What is the difference between HashMap and HashTable?


  • HashMap :

    • Not synchronized.

    • Allows one null key and multiple null values.

  • HashTable :

    • Synchronized.

    • Does not allow null keys or values.

22. What is the use of the finalize() method?


  • The finalize() method is called by the garbage collector before reclaiming the memory of an object. It is used for cleanup activities like closing files or database connections.

23. What is method chaining in Java?


  • Method chaining allows calling multiple methods on the same object in a single statement by returning this from methods.

  • Example :

    class Demo {
      Demo method1() {
        System.out.println("Method1");
        return this;
      }
      Demo method2() {
        System.out.println("Method2");
        return this;
      }
    }
    public class Main {
      public static void main(String[] args) {
        new Demo().method1().method2();
      }
    }

24. What is the difference between Abstract class and Concrete class?


  • Abstract Class : Cannot be instantiated; may have abstract and concrete methods.

  • Concrete Class : Can be instantiated and must implement all abstract methods if it extends an abstract class.

25. Explain the try-with-resources statement.


  • The try-with-resources statement is used to automatically close resources like streams or files that implement the AutoCloseable interface.

  • Example :

    try (BufferedReader br = new BufferedReader(new FileReader("file.txt"))) {
      System.out.println(br.readLine());
    } catch (IOException e) {
      e.printStackTrace();
    }

26. Explain the volatile keyword in Java


  • The volatile keyword ensures that the value of a variable is always read from the main memory, preventing threads from caching the value.

27. What is the difference between wait() and sleep()?


  • wait() : Used for thread communication; releases the lock.

  • sleep() : Pauses execution for a specified time; does not release the lock.

28. What are Comparator and Comparable in Java?


  • Comparable : Used to define natural ordering by overriding compareTo().

  • Comparator : Used for custom ordering by overriding compare().

  • Example with Comparator :

    import java.util.*;

    class Student {
      int id; String name;
      Student(int id, String name) {
        this.id = id; this.name = name;
      }
    }
    class SortByName implements Comparator<> {
      public int compare(Student a, Student b) {
        return a.name.compareTo(b.name);
      }
    }
    public class Main {
      public static void main(String[] args) {
        List<Student> list = new ArrayList<>();
        list.add(new Student(1, "John"));
        list.add(new Student(2, "Alice"));

        Collections.sort(list, new SortByName());
        for (Student s : list) {
          System.out.println(s.name);
        }
      }
    }

1. What is the difference between HashMap and ConcurrentHashMap?


  • HashMap :

    • Not thread-safe.

    • Allows one null key and multiple null values.

  • ConcurrentHashMap :

    • Thread-safe using segment-level locking (concurrency level).

    • Does not allow null keys or values.

2. What is the significance of the synchronized keyword in Java?


  • The synchronized keyword is used to control access to critical sections or blocks of code by threads. It ensures only one thread can execute a block of code or a method at a time.

    • Can be applied to methods or blocks.

    • Helps prevent race conditions.

3. What is a Singleton Design Pattern? How can you implement it?


  • A Singleton Design Pattern ensures a class has only one instance globally.

  • Example :

    public class Singleton {
      private static Singleton instance;

      private Singleton() {}

      public static synchronized Singleton getInstance() {
        if (instance == null) {
          instance = new Singleton();
        }
      return instance;
      }
    }

4. What is the difference between Callable and Runnable?


  • Runnable : Does not return a result or throw checked exceptions.

  • Callable : Returns a result and can throw checked exceptions.

5. What is the use of volatile in Java?


  • The volatile keyword ensures that changes to a variable are visible to all threads. It prevents threads from caching the variable's value and always reads it from main memory.

6. Explain Java Memory Model (JMM).


  • The JMM defines how threads interact through memory and ensures :

    • Visibility of changes to variables across threads.

    • Ordering of instructions (happens-before relationship).

7. How does Garbage Collection work in Java?


  • Garbage Collection (GC) automatically reclaims memory from objects no longer referenced.

  • Phases :

    • Mark : Identify unreachable objects.

    • Sweep : Reclaim memory.

    • Compact : Reorganize memory.

  • Collectors :

    • Serial, Parallel, CMS (Concurrent Mark-Sweep), G1 (Garbage First).

8. What is the difference between Comparable and Comparator?


  • Comparable :

    • Used for natural ordering.

    • Implements compareTo().

    • Example :

      Collections.sort(list);.

  • Comparator :

    • Used for custom ordering.

    • Implements compare().

    • Example :

      Collections.sort(list, new ComparatorClass());.

9. What are Java Streams?


  • Streams in Java (introduced in Java 8) are used for processing sequences of elements with functional-style operations.

  • Operations :

    • Intermediate : map(), filter().

    • Terminal : forEach(), collect().

  • Example :

    List<String> names = Arrays.asList("John", "Jane", "Jack");
    names.stream()
      .filter(name -> name.startsWith("J"))
      .map(String::toUpperCase)
      .forEach(System.out::println);

10. What is the difference between ForkJoinPool and ExecutorService?


  • ForkJoinPool :

    • Suitable for divide-and-conquer tasks.

    • Uses work-stealing algorithm.

  • ExecutorService :

    • Suitable for managing threads in a pool.

    • Does not support divide-and-conquer.

11. What is Dependency Injection (DI)?


  • DI is a design pattern where objects are provided with their dependencies at runtime, promoting loose coupling.

  • Types :

    • Constructor Injection.

18. What is the difference between fail-fast and fail-safe iterators?


  • Fail-fast : Throws ConcurrentModificationException if the collection is modified during iteration (e.g., ArrayList, HashMap).

  • Fail-safe : Works on a copy of the collection and does not throw an exception (e.g., CopyOnWriteArrayList, ConcurrentHashMap).

19. What is the transient keyword in Java?


  • The transient keyword prevents a variable from being serialized. Transient variables are skipped during the serialization process.

20. What are the different types of references in Java?


  • Strong Reference : Default type; object is not eligible for garbage collection unless explicitly nullified.

  • Weak Reference : Referenced object is collected during the next GC cycle.

  • Soft Reference : Collected only if memory is low.

  • Phantom Reference : Used to schedule cleanup actions before an object is removed from memory.

22. What is the hashCode() and equals() contract?


  • If two objects are equal, their hashCode() must return the same value.

  • If two objects have the same hashCode(), they may or may not be equal.

  • equals() checks logical equality, and hashCode() is used in hashing-based collections (e.g., HashMap).

28. Explain the concept of Deadlock in Java.


  • A deadlock occurs when two or more threads are blocked forever, waiting for each other to release resources.

  • Example :

    class Deadlock {
      public static void main(String[] args) {
        final String resource1 = "Resource1";
        final String resource2 = "Resource2";

        Thread t1 = new Thread(() -> {
          synchronized (resource1) {
            System.out.println("Thread 1 locked Resource 1");
            synchronized (resource2) {
              System.out.println("Thread 1 locked Resource 2");
            }
          }
        });

      Thread t2 = new Thread(() -> {
        synchronized (resource2) {
          System.out.println("Thread 2 locked Resource 2");
          synchronized (resource1) {
            System.out.println("Thread 2 locked Resource 1");
          }
        }
      });

      t1.start();
      t2.start();
      }
    }

1. Explain the key differences between synchronized and Lock in Java.


  • synchronized :

    • Implicit locking mechanism.

    • Acquires and releases the lock automatically.

    • Cannot interrupt threads waiting for a lock.

  • Lock :

    • Explicit locking mechanism (java.util.concurrent.locks).

    • Provides more flexibility, such as tryLock() for timed locking.

    • Can interrupt threads waiting for a lock.

2. How would you optimize a Java application for performance?


  • Efficient Algorithms : Use appropriate data structures and algorithms.

  • Memory Management : Minimize object creation, use pooling.

  • Concurrency : Use thread pools, avoid contention.

  • Profiling Tools : Use tools like JVisualVM, YourKit to identify bottlenecks.

  • Database Optimization : Indexing, connection pooling.

  • Garbage Collection Tuning : Configure GC as per workload.

3. Explain the importance of CompletableFuture in Java.


  • CompletableFuture is used for asynchronous programming. It supports chaining multiple tasks and combining results.

  • Example :

    CompletableFuture.supplyAsync(() -> "Hello")
      .thenApply(result -> result + " World")
      .thenAccept(System.out::println); // Output: Hello World

4. What is the difference between a Heap and a Stack in memory management?


  • Heap : Stores objects and global variables. Managed by the garbage collector.

  • Stack : Stores method-specific data like local variables and function calls. Follows LIFO (Last In, First Out).

5. What is the significance of immutability in Java?


  • Thread-safe by design.

  • Easy to use as keys in collections.

  • Prevents accidental modifications.

  • Examples: String, Integer, LocalDate.

6. How would you troubleshoot OutOfMemoryError?


  • Analyze heap dumps using tools like Eclipse MAT.

  • Identify memory leaks.

  • Check for unbounded collections.

  • Optimize object creation.

  • Increase heap size if necessary (-Xms and -Xmx JVM options).

7. Explain the role of GC (Garbage Collector) and its types.


  • GC automates memory management by reclaiming unused objects.

  • Types of Collectors :

    • Serial GC : Single-threaded, best for small applications.

    • Parallel GC : Multi-threaded, good for throughput.

    • CMS GC : Low latency, concurrent phases.

    • G1 GC : Balances throughput and low latency.

8. Explain the Producer-Consumer problem and its solution in Java.


  • The Producer-Consumer problem involves synchronization between threads.

  • Using BlockingQueue :

  • Example :

    BlockingQueue<Integer> queue = new ArrayBlockingQueue<>(10);
      new Thread(() -> {
        try {
          queue.put(1); // Producer
        } catch (InterruptedException e) { }
      }).start();
    new Thread(() -> {
      try {
        queue.take(); // Consumer
      } catch (InterruptedException e) { }
    }).start();

13. How would you implement the Factory Design Pattern?


  • The Factory Pattern creates objects without exposing the creation logic.

  • Example :

    interface Shape { void draw(); }

    class Circle implements Shape {
      public void draw() { System.out.println("Circle"); }

    class ShapeFactory {

          return new Circle();
        }
      return null;
      }
    }

14. What is the Singleton Design Pattern? How do you make it thread-safe?


  • Thread-safe Singleton Example:

  • public class Singleton {
      private static volatile Singleton instance;

      private Singleton() {}

      public static Singleton getInstance() {
        if (instance == null) {
          synchronized (Singleton.class) {
            if (instance == null) {
              instance = new Singleton();
            }
          }
        }
      return instance;
      }
    }

15. What is the N+1 query problem in Hibernate? How do you solve it?


  • The N+1 query problem occurs when an additional query is executed for each element in a collection.

  • Use JOIN FETCH or batch fetching.

  • List<Department> departments = session.createQuery(
      "FROM Department d JOIN FETCH d.employees").list();

  • Reduce transaction scope.

  • Leverage caching mechanisms (e.g., EhCache, Redis).
