Arithmetic Functions

Arithmetic functions are built-in functions that perform mathematical calculations on numeric data types.


    • These functions enable operations like rounding, generating absolute values, calculating power, and more.
    • They are essential for data analysis, financial calculations, and transforming numeric data.
    • They simplify complex arithmetic operations and are used in SELECT statements, WHERE clauses, or as part of other SQL operations.

Key Arithmetic Functions

Function Purpose Description Uses Limits
ABS(x) Return absolute value Removes the negative sign from a number. Calculate differences, normalize values. Only works on numeric data.
CEIL(x) / CEILING(x) Round up to nearest integer Rounds a number upwards to the smallest integer greater than or equal to the number. Inventory calculations, pricing adjustments. Cannot handle NULL values or non-numeric data.
FLOOR(x) Round down to nearest integer Rounds a number downwards to the largest integer less than or equal to the number. Logistics and budgeting scenarios. Same as CEIL( ).
ROUND(x, d) Round to specified decimals Rounds a number to the specified number of decimal places. Financial calculations, reports formatting. Overuse may lead to rounding errors over multiple computations.
MOD(x, y) / x % y Find remainder of division Returns the remainder when one number is divided by another. Scheduling (e.g., odd/even weeks), grouping. Division by zero will throw an error.
POWER(x, y) Exponentiation Raises a number to the power of another number. Exponential growth, compound interest calculations. Overflows for very large exponents or bases.
EXP(x) Calculate e^x Returns the exponential value of a number (e^x). Predictive models, population growth, scientific calculations. Limited to numerical data; large exponents can cause overflow errors.
LN(x) Find natural logarithm Returns the natural logarithm (log base e) of a number. Normalizing data, solving logarithmic equations. Undefined for negative or zero values.
LOG( base, x ) Find logarithm of specified base Returns the logarithm of a number with a given base (base-10 or custom depending on the database). Financial modeling, analyzing rates of change. Undefined for non-positive values; some databases have limited base support.
SQRT(x) Find square root Returns the square root of a number. Standard deviation, geometric calculations. Undefined for negative values; returns NULL in such cases.

Key Notes on Limits:

  • NULL Values:- Most arithmetic functions return NULL when applied to NULL values. Always handle NULL explicitly with functions like COALESCE.
  • Overflow Errors:- Functions like POWER and EXP can produce extremely large numbers, leading to overflows. Be cautious when working with high exponents or bases.
  • Division by Zero:- The MOD() or % function will throw errors if the divisor is zero.
  • Non-Numeric Data:- Functions are strictly for numeric data types. Applying them to text or incompatible types results in errors.

Detailed Explanation with Examples

1. ABS (Absolute Value)

Returns the absolute value of a number (removes the negative sign if present).

Syntax

ABS ( number )

Scenarios

  • Financial Analysis:- Calculate the absolute difference in profit/loss across regions.
  • Error Handling:- Remove negative values caused by errors.

Examples

Scenario 1:- Basic example

SELECT ABS(-45) AS AbsoluteValue ; - - SQL Server, MySQL
- - Output: 45
SELECT ABS(-45) AS AbsoluteValue FROM DUAL ; - - Oracle
- - Output: 45

Scenario 2:- Find the absolute difference between budgeted_sales and actual_sales

SELECT department_id,
ABS ( budgeted_sales - actual_sales ) AS difference
FROM sales_data ;

2. CEIL and FLOOR

Rounds a number up to the nearest integer.

Syntax

CEIL ( number ) - - in Oracle, MySQL.
CEILING ( number ) - - in SQL Server.

Scenarios

  • Inventory Management:- Round up the number of required boxes to pack items.
  • Pricing Adjustments:- Round prices up to the nearest dollar.

Scenario 1:- Basic example ( Pricing adjustments where values are rounded up. )

SELECT CEIL(12.34) AS RoundedUp ; - - SQL Server, MySQL
- - Output: 13
SELECT CEIL(12.34) AS RoundedUp FROM DUAL ; - - Oracle
- - Output : 13

Scenario 2:- Calculate the minimum number of cartons needed for items.

SELECT product_id,
CEIL( quantity / carton_size ) AS cartons_needed
FROM inventory ;

3. FLOOR( )

Rounds a number down to the nearest integer.

Syntax

FLOOR ( number )

Scenarios

  • Logistics:- Calculate full truckloads required for shipping.
  • Budgeting:- Allocate full dollar amounts while ignoring cents.

Scenario 1:- Basic example

SELECT FLOOR(12.34) AS Roundedown ; - - SQL Server, MySQL
- - Output: 12
SELECT FLOOR(12.34) AS RoundedUp FROM DUAL ; - - Oracle
- - Output : 12

Scenario 2:- Calculate the number of full containers required for shipments.

SELECT shipment_id,
FLOOR( weight / container_capacity ) AS full_containers
FROM shipments ;

4. ROUND( )

Rounds a number to a specified number of decimal places.

Syntax

ROUND ( number, decimals )

Scenarios

  • Finance:- Round monetary values to two decimal places.
  • Data Presentation:- Format values for reports.

Scenario 1:- Basic example ( Financial calculations where rounding to a specific precision is required. )

SELECT ROUND(123.4567, 2) AS Roundedown ; - - SQL Server, MySQL
- - Output: 123.46
SELECT ROUND(123.4567, 2) AS RoundedUp FROM DUAL ; - - Oracle
- - Output : 123.46

Scenario 2:- Round the average scores to one decimal place.

SELECT student_id,
ROUND( AVG( score), 1 ) AS average_score
FROM exam_results
GROUP BY student_id ;

5. MOD( ) or % (Modulo)

Returns the remainder of a division operation.

Syntax

MOD (number, divisor ) - - Oracle, MySQL
number % divisor - - SQL Server

Scenarios

  • Scheduling:- Determine odd/even weeks for task assignments.
  • Grouping:- Assign records into groups based on remainders.

Scenario 1:- Basic example ( Grouping operations (e.g., odd/even checks) )

SELECT MOD(23, 3) AS ModResult ; - - MySQL
- - Output: 3
SELECT MOD(34, 4) AS ModResult FROM DUAL ; - - Oracle
- - Output: 1
SELECT 15 % 4 AS ModResult ; - - MySQL
- - Output: 3

Scenario 2:- Identify employees assigned to odd-numbered groups.

SELECT employee_id,
MOD(employee_id, 2) AS group_assignment
FROM employees
WHERE MOD( employee_id, 2 ) = 1 ;

6. POWER( )

Raises a number to the power of another number.

Syntax

POWER (base, exponent )

Scenarios

  • Finance:- Calculate compound interest.
  • Mathematics:- Compute exponential growth or decay.

Scenario 1:- Basic example ( Statistical computations and geometric calculations )

SELECT POWER(2, 3) AS Powerof2 ; - - SQL Server, MySQL
- - Output: 8
SELECT POWER(2, 3) AS Powerof2 FROM DUAL ; - - Oracle
- - Output: 8

Scenario 2:- Calculate compound interest for accounts.

SELECT account_id,
principal_amount * POWER( 1 + interest_rate, years ) AS total_amount
FROM accounts ;

7. EXP( )

Calculates the exponential value of a number (e^x).

Syntax

EXP ( Number )

Scenarios

  • Statistics:- Model exponential growth (e.g., population growth)
  • Data Science:- Calculate natural exponential values in algorithms.

Scenario 1:- Basic example ( Financial calculations like compound interest. )

SELECT EXP(2) AS Exp2Result ; - - SQL Server, MySQL
- - Output: 7.389
SELECT EXP(5) AS Exp2Result FROM DUAL ; - - Oracle
- - Output: 148.413

Scenario 2:- Predict population growth using an exponential formula.

SELECT city_id,
EXP( growth_rate * years ) * initial_population AS Total_population
FROM population ;

8. LN( )

Returns the natural logarithm of a number.

Syntax

LN ( Number )

Scenarios

  • Data Science:- Normalize data.
  • Mathematics:- Solve equations involving logarithms.

Scenario 1:- Basic example

SELECT LN(10) AS NaturalLog10 ; - - SQL Server, MySQL
- - Output: 2.302
SELECT LN(7) AS NaturalLog7 FROM DUAL ; - - Oracle
- - Output: 1.945

Scenario 2:- Calculate the natural logarithm of revenue.

SELECT department_id,
LN( revenue ) AS logrth_revenue
FROM Financials ;

9. LOG()

Returns the logarithm of a number with a specified base.

Syntax

LOG ( base, number ) - - MySQL
LOG ( number ) - - SQL Server (base 10 by default)

Scenarios

  • Analytics:- Perform base-specific logarithmic transformations.
  • Math:- Solve problems involving logarithms.

Scenario 1:- Basic example ( Financial calculations like compound interest. )

SELECT LOG(10, 100) AS Logarithm ; - - SQL Server, MySQL
- - Output: 2
SELECT LOG(10, 100) AS NaturalLog7 FROM DUAL ; - - Oracle
- - Output: 2

Scenario 2:- Calculate base-10 logarithms of user engagement rates.

SELECT user_id,
LOG(10, engagement_rate) AS log_engagement
FROM user_metrics ;

10. SQRT()

Returns the square root of a number.

Syntax

SQRT ( number )

Scenarios

  • Statistics:- Calculate the standard deviation.
  • Engineering:- Solve geometric problems.

Scenario 1:- Basic example

SELECT SQRT(16) AS SquareRoot ; - - SQL Server, MySQL
- - Output: 4
SELECT SQRT(16) AS SquareRoot FROM DUAL ; - - Oracle
- - Output: 4

Scenario 2:- Compute the standard deviation of sales.

SELECT SQRT(AVG( sales ) - POWER(AVG( sales ), 2)) AS Sqrt_diff
FROM sales_data ;

11. PI()

Calculate the circumference of a circle.

Syntax

PI ( )

Scenario 1:- Basic example ( Returns the mathematical constant π. )

SELECT PI() AS PiValue ; - - SQL Server, MySQL
- - Output: 3.141592653589793
SELECT PI() AS PiValue FROM DUAL ; - - Oracle
- - Output: 3.141592653589793

Scenario 2:- Calculate the circumference of a circle.

SELECT 2 * PI() * 5 AS circumference
FROM DUAL ;
- - Result: 31.41592653589793

12. TRUNCATE(x, d) - ( MySQL-Specific )

Truncates a number to a specific number of decimal places without rounding.

Syntax

TRUNCATE ( number, decimals )

Scenario 1:- Basic example

SELECT TRUNCATE (359.4567, 2) AS TruncValue ;
- - Output: 359.45

Scenario 2:- Truncate product prices to 2 decimals.

SELECT TRUNCATE (Price, 2) AS TruncatedPrice
FROM Products ;

13. SIGN(x)

Identify the sign of a number.

Syntax

SIGN ( number )

Basic example

SELECT SIGN(-10) AS sign_of_negative
SELECT SIGN(0) AS sign_of_zero
SELECT SIGN(10) AS sign_of_positive ; - - Output: -1 (for -10), 0 (for 0), 1 (for 10)

14. RANDOM() / RAND()

Generate random numbers.

Syntax

RAND ( ) - - MySQL, SQL Server
DBMS_RANDOM ( ) - - Oracle

Scenario 1:- Basic example

SELECT RAND() AS random_value ;
- - Result: A random value between 0 and 1 (e.g., 0.726345).

SELECT RAND() * 100 AS scaled_random ; - - SQL Server
- - Result: A random number between 0 and 100 (e.g., 56.348734).

SELECT DBMS_RANDOM.VALUE(1, 10) AS random_1_10_10 FROM DUAL ; - - Oracle
- - Result: A random value between 1 and 10.

Key Notes on Limits

  • PI() : Fixed value and cannot be modified.
  • TRUNCATE(x, d) : Negative d values may reduce precision; not all databases support it natively (e.g., SQL Server uses ROUND(x, d, 1) for truncation).
  • SIGN(x) : Undefined for NULL inputs.
  • RANDOM() / RAND() :
    • Randomness quality varies between databases.
    • Use seeds (RAND(seed) in MySQL or SETSEED in Oracle) for reproducible results if required.

Advanced Examples

1. Using Arithmetic Functions in WHERE Clause

Scenario :- Retrieves orders where the absolute value of the discount exceeds 10.

SELECT * FROM Orders
WHERE ABS(Discount) > 10 ;

2. Calculate Compound Interest

Scenario :- Retrieves orders where the absolute value of the discount exceeds 10.

SELECT Principal, Rate, Years,
Principal * POWER( ( 1 + Rate / 100 ), Years ) AS Compound_Interest
FROM Investments ;

3. Determine Odd or Even

Scenario :- Returns 1 for odd Employee IDs and 0 for even.

SELECT EmployeeID, MOD(EmployeeID, 2) AS IsOdd
FROM Employees ;

4. Rounding and Truncation

Scenario :- Compares rounded and truncated prices.

SELECT ProductID, ROUND(Price, 2) AS RoundedPrice,
TRUNCATE ( Price, 2 ) AS Truncated_Price FROM Products ;

5. Randomized Sampling

Scenario :- Randomly selects customers with a probability greater than 0.5.

SELECT CustomerID
FROM Customers WHERE RAND() > 0.5 ;

Common Errors and Fixes

1. Null Values

    • Any arithmetic function with NULL input returns NULL.
    • Fix : Use COALESCE() to replace NULL values.
      • SELECT ABS( COALESCE( value, 0 ) ) FROM Customers ;

2. Division by Zero

  • Fix : Use NULLIF() to handle zero values.
    • SELECT 100 / NULLIF( column, 0 ) FROM Table ;

3. Invalid Input for SQRT

  • Negative numbers in SQRT throw errors.
  • Fix : Validate input using a CASE statement.
    • SELECT CASE WHEN value >= 0
    THEN SQRT(value) ELSE NULL END AS Result FROM Table ;
