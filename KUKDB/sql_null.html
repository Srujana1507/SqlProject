NULL


NULL represents a missing, undefined, or unknown value.


  • It is not equivalent to zero, an empty string, or any other default value.
  • NULL in SQL represents the absence of a value in a column.
  • NULL is a unique marker used to signify that no value exists for a given field.

Key Points about NULL

  • No Value: NULL means the value is not present in the database.
  • Not Equal to Anything: NULL is not equal to 0, an empty string (''), or even to another NULL. You cannot compare NULL values using the = operator.
  • Three-Valued Logic :In SQL, operations involving NULL result in one of three possible outcomes: TRUE, FALSE, or UNKNOWN.
  • Special SQL functions ( IS NULL and IS NOT NULL ) and conditions are required to handle NULL.

Purpose and Use Cases

  • Identify Missing Data : Helps detect incomplete records.
  • Filter Queries: Use IS NULL or IS NOT NULL to filter data.
  • Default Values :Insert NULL to signify that data is not yet available.

Scenarios with NULL

  • Scenario 1:- Retrieves rows where the Department column has no value.
SELECT * FROM Employees
WHERE department IS NULL ;

  • Scenario 2:- Find all rows where the address column is NULL.
SELECT Cust_id , name FROM customers
WHERE address IS NULL ;

  • Scenario 3:- Retrieve all employee details who are having salary.
SELECT employee_id , name , salary FROM employee
WHERE salary IS NOT NULL ;

  • Scenario 4:- NULL cannot be compared using regular operators like = or !=.
SELECT * FROM employee
WHERE salary = NULL ;

-- Always returns no rows

  • Scenario 5:- NULL in Arithmetic Operations Arithmetic with NULL results in NULL.
SELECT 5 + NULL
as Result FROM DUAL ;

-- Result is NULL

  • Scenario 6:- a NULL explicitly or by leaving a column blank (if allowed by schema).
INSERT INTO employees ( employee_id , name, salary )
VALUES ( 101, 'John Doe' , NULL ) ;

-- Result is NULL

Handling NULL with Functions


    1.COALESCE : Returns the first non-NULL value.
SELECT COALESCE(Phone, 'N/A') AS Contact
FROM DUAL ;

    2.NVL (Oracle-specific): Replaces NULL with a specified value.
SELECT NVL( Salary, 0 ) AS Salary
FROM employee ;

    3.ISNULL (SQL Server-specific): Similar to NVL.
SELECT ISNULL(Salary, 0) AS Salary
FROM employee ;

    4. IFNULL (MySQL-specific): Replaces NULL with a value.
SELECT IFNULL(Salary, 0) AS Salary
FROM employee ;

Sorting data with NULLs


By default, NULL values are placed at the end of a result set when sorting in ascending order.


Oracle and PostgreSQL

SELECT name ,salary
FROM employees
ORDER BY salary ASC ;

  • NULLS LAST in Ascending Order
SELECT * FROM employees
ORDER BY salary ASC NULLS LAST ;

  • NULLS FIRST in Descending Order
SELECT * FROM employees
ORDER BY salary DESC NULLS FIRST ;

Sorting by Multiple Columns Including NULLs

When sorting by multiple columns, NULL handling can be specified for each column individually.

  • Sort by Department (NULLs last) and then by Salary (ascending)

PostgreSQL/Oracle

SELECT *
FROM employees
ORDER BY Department NULLS LAST ,
Salary DESC ;

MySQL

  • Does not support NULLS FIRST or NULLS LAST explicitly
  • Use a workaround with CASE statements
SELECT * FROM employees
ORDER BY ( Salary IS NULL ), Salary ASC ;

  • Use CASE statements to control NULL positioning
SELECT * FROM employees
ORDER BY CASE WHEN Salary IS NULL THEN 1
ELSE 0 END , Salary ASC ;

Advanced Scenarios


1.NULL in Aggregate Functions

  • Aggregate functions generally ignore NULL values.
SELECT AVG( Salary ) AS Average_Salary FROM employees ;
Note : If some Salary values are NULL, they are excluded from the average calculation.

-- Count ignores NULLs
SELECT COUNT(salary) AS total_salaries FROM employees ;
-- COUNT( * ) includes NULLs
SELECT COUNT(*) AS total_rows FROM employees ;

2. NULL in Conditional Statements ( CASE )

  • Display as 'Not provided ' if employee don't have salary. Else display as Provided.
SELECT employee_id ,
    CASE
      WHEN Salary IS NULL THEN 'Not Provided'
      ELSE 'Provided'
    END AS Salary_Status
FROM employees ;

3. NULL in Joins

  • NULL values can affect joins. Below is example
SELECT * FROM employees E
LEFT JOIN Departments D
ON E.Department_ID = D.Department_ID ;
If Department_ID in Employees is NULL, the row still appears in the result with NULL for Departments fields.

  • Write a query to display employees without projects
SELECT e.employee_id, p.project_name
FROM employees e
LEFT JOIN Projects p
ON e.employee_id = p.employee_id
WHERE p.project_name IS NULL ;
If Department_ID in Employees is NULL, the row still appears in the result with NULL for Departments fields.

Common Errors


1. Incorrect NULL Comparison:

SELECT * FROM employees E
WHERE Salary = NULL ; -- Incorrect

2. Unexpected Results with Joins


    A NULL key in a table can prevent matches in a join, leading to missing rows.

3. Misusing Functions with NULL


    Some functions do not handle NULL as expected if not explicitly accounted for.
