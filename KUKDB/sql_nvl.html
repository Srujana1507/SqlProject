NVL

The NVL function is used to handle NULL values.


  • It replaces NULL with a specified value, ensuring that operations and results involving NULL behave as intended.
  • It’s primarily available in Oracle databases, while other database systems have similar functions like COALESCE or ISNULL

How it Works

  • If expression is not NULL, NVL returns its value.
  • If expression is NULL, NVL returns replacement_value.

Syntax

NVL (expression,replacement_value )

- - expression: The column or expression to evaluate for NULL.
- - replacement_value: The value to substitute if the expression evaluates to NULL.

Examples

1. Replacing NULL with Default Value

SELECT NVL (discount,0) AS effective_discount
FROM sales ;

- - If discount contains NULL, it will be replaced with 0.
- - This is particularly useful in arithmetic operations to avoid unexpected results due to NULL.

2. Handling NULL in String Columns

Scenario :- Display 'Not Available' wherever a column like remarks contains NULL.

SELECT NVL (remarks, 'Not Available' ) AS comments
FROM feedback ;

- - Ensure the replacement value ('Not Available') matches the data type of the column.

3. Calculating Total with NULL Handling

Scenario :- Calculate total price (quantity * price), replace NULL in price with 0.

SELECT item_id, quantity,
NVL (price, 0) * quantity AS total_price
FROM orders ;

- - If price is NULL, NVL(price, 0) ensures the calculation works correctly by using 0 as the price.

4. Using NVL with Joins

Scenario :- When performing a join, you want to replace NULL department names with 'Unknown Department'.

SELECT e.name, NVL( d.department_name, 'Unknown Department' )
AS department
FROM employees e
LEFT JOIN departments d ON e.department_id = d.department_id ;

- - Use NVL in outer joins to handle NULL values from missing relationships effectively.

5: Defaulting to a Value for Reporting

Scenario :- Display 0 for missing sales data in a monthly report.

SELECT month, NVL(total_sales, 0) AS reported_sales
FROM sales_report ;

- - Replace missing data with meaningful defaults in reporting scenarios to avoid gaps in the report.

6: Substituting NULL in Grouping

Scenario :- When grouping data by a category, replace NULL categories with 'Uncategorized'.

SELECT NVL(category, 'Uncategorized') AS category,
COUNT(*) AS item_count
FROM inventory GROUP BY NVL(category, 'Uncategorized') ;

- - Using NVL ensures consistent grouping even for NULL values.

7: Combining NVL with String Concatenation

Scenario :- You want to show a message that includes either a customer's phone number or 'No Phone Provided'.

SELECT customer_name, 'Phone: ' || NVL(phone, 'No Phone Provided') AS contact_info
FROM customers ;

- - Use NVL to avoid incomplete messages when concatenating strings.

8: Handling Multiple Columns with NULL

Scenario :- You want to prioritize a value in backup_email if email is NULL.

SELECT NVL(email, backup_email) AS primary_contact
FROM users ;

- - Use NVL to seamlessly fall back to alternate values.

9: Using NVL in Calculations with Derived Columns

Scenario :- You want to calculate final marks where missing marks are treated as 0.

SELECT student_id, NVL(exam1,0) +NVL(exam2,0) AS total_marks
FROM marks ;

- - Ensure the default values align with the business logic for the calculation.

10: Prioritizing NVL in CASE Statements

Scenario :- You want to handle NULL in a CASE statement for flexible categorization.

SELECT customer_name,
    CASE
      WHEN NVL(discount, 0) > 10 THEN 'High Discount'
      ELSE 'Low or No Discount'
    END AS discount_category
FROM customers ;

- - NVL ensures the CASE logic processes correctly even with NULL values.
